Proyecto 1 — Mini App de Galería

Descripción definitiva: app de galería con miniaturas, modal accesible y lazy-loading. Diseñada para funcionamiento fluido en móvil y escritorio, con atención a la accesibilidad y rendimiento.

Características principales

  • Miniaturas con navegación y selección por teclado.
  • Modal ampliable con controles prev/next y cierre con Esc.
  • Imágenes optimizadas y lazy-loading progresivo.
  • Interfaz responsiva y controles táctiles para móviles.

Tecnologías

HTML5, CSS3 (flex/grid), JavaScript (DOM y accesibilidad). Implementación ligera sin frameworks.

  • HTML semántico y ARIA donde procede.
  • CSS variables y transiciones suaves.
  • JavaScript para modal y lazy-load.
