Proyecto 1 — Mini App de Galería

Este proyecto es un ejemplo didáctico que muestra una galería simple con HTML/CSS y algo de JavaScript para la interactividad. Objetivo: presentar imágenes, descripción técnica y enlace a la demo del proyecto.

Descripción corta

Proyecto orientado a practicar layout responsive, interacción básica y organización de recursos. Ideal como primer proyecto para mostrar en el portfolio.

Tecnologías

  • HTML5 / CSS3
  • JavaScript (interactividad mínima)
  • Imágenes de ejemplo
