Proyecto 2 — Interacción y pequeñas animaciones

Proyecto 2 muestra ejemplos de interacción con JavaScript: pequeñas animaciones, manipulación del DOM y componentes sencillos. Ideal para demostrar comportamiento dinámico.

Descripción corta

En este proyecto se exploran técnicas como animaciones CSS, respuestas a eventos del usuario y componentes reutilizables. Es un proyecto educativo para practicar JavaScript del lado del cliente.

Tecnologías

  • HTML5 / CSS3
  • JavaScript (eventos y animaciones)
  • Imágenes de ejemplo
